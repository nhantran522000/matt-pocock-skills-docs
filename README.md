# Matt Pocock's Agent Skills — Docs Mirror

Mirror of the documentation for all 27 agent skills from [AI Hero's Skills page](https://www.aihero.dev/skills), crawled on **2026-10-31** from the site's markdown versions (`<page>.md`).

All content is by **Matt Pocock**. The same docs are MIT-licensed in the source repo [mattpocock/skills](https://github.com/mattpocock/skills); this mirror is for reading/reference convenience.

All docs live as flat markdown files in [`notebook-source/`](notebook-source/).

## Learn with NotebookLM

The [`notebook-source/`](notebook-source/) folder is prepared as a source set for [Google NotebookLM](https://notebooklm.google.com), so you can learn these skills conversationally:

1. Create a new notebook at [notebooklm.google.com](https://notebooklm.google.com)
2. Add the 31 markdown files from `notebook-source/` as sources — upload the files directly, or add this GitHub repo as a source
3. Ask questions ("when do I use grill-me vs grill-with-docs?"), generate study guides, or an Audio Overview to listen to

## Install the skills

- Any agent: `npx skills@latest add mattpocock/skills` (update with `npx skills update`)
- Claude Code: `claude plugins install mattpocock-skills` (updates automatically)
